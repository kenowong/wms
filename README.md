# 进销存管理系统

轻量级、可离线、自托管的进销存（采购—库存—销售—财务）一体化管理系统。面向中小微企业、个体经营者与项目型团队，覆盖商品、往来单位、仓库、采购销售、库存、财务、发票、项目等全流程，并内置**发票图片/PDF 智能识别**、**单据审核流**、**期末封账结转**等企业级能力。

> 当前版本：**v2.8.2**

---

## ✨ 核心特性

- **纯离线、自托管**：数据全部存在本地 SQLite，不上云、不依赖外部服务，隐私可控。
- **一体化业务闭环**：商品档案 → 采购入库 → 库存 → 销售出库 → 收付款 → 发票 → 财务报表，全链路打通。
- **发票智能识别**：上传发票图片或 PDF，自动识别发票代码、号码、日期、金额（增值税二维码优先 + 中文 OCR 兜底），识别结果自动回填表单。
- **单据审核流**：采购/销售/发票/收付款/费用/盘点/对账支持「草稿 → 已审核 → 已作废」状态流转；已审核单据锁死，反审核/作废自动回滚库存与余额，保障数据严谨。
- **期末封账与结转**：按年度锁账，禁止历史年度业务变动，并自动生成下年期初余额，支撑年度核算。
- **多维权限**：内置管理员 / 操作员 / 查看员三角色，并支持按模块细粒度授权。
- **多端可用**：Windows 桌面安装包、NAS / Docker 自部署、手机网页（自适应）、以及可打包上架 App Store / Google Play 的移动端 App。
- **数据可迁移**：商品、往来单位支持 CSV 导入导出；数据库一键备份 / 恢复。

## 📦 功能模块

### 一、基础档案
- **商品档案**：名称、规格、型号（规格/型号独立字段）、单位、分类、品牌、参考进价售价等。
- **商品分类管理**
- **品牌管理**
- **往来单位**：供应商 / 客户 / 两者兼有，统一档案。
- **仓库管理**：多仓库维护。
- **计量单位**：内置 39 个常用单位（个、件、箱、公斤、米…），缺则自动补充。

### 二、采购与销售
- **采购入库**：录入供应商、仓库、商品明细、金额，可关联发票需求。
- **销售出库**：录入客户、仓库、商品明细，含发票需求与状态流转。
- **出入库条码扫码录入**：支持扫码快速录入商品。
- **耗材领用**：低值易耗品领用管理，单位可下拉选择。

### 三、库存管理
- **库存台账**：实时库存查询。
- **库存盘点**：盘点单录入、与账面差异核对；支持审核 / 反审核（反审核回滚库存）。
- **库存预警**：低于下限自动提醒。
- **库存流水**：每一笔出入库变动可追溯。

### 四、财务管理
- **银行账户**：多账户维护。
- **收付款**：收款 / 付款单，支持作废（作废自动回滚银行余额）。
- **对账管理**：应收应付对账。

### 五、发票管理
- **进项发票 / 出项发票**：统一录入界面。
- **发票图片 / PDF 上传 + 自动识别**（详见下方「发票智能识别」）。
- 发票与收付款、订单关联。

### 六、项目管理
- **项目台账**：项目登记与总览。
- **项目流程（任务/阶段）**：名称、负责人、起止日期、进度、状态、备注，可增删改。
- **甘特图**：按任务起止日期绘制时间轴 + 进度叠加 + 今日红线，纯前端无依赖。

### 七、数据报表
- 多维度经营报表（采购、销售、库存、财务汇总）。

### 八、系统管理
- **用户与权限管理**：登录页、用户管理、三角色、模块级细粒度授权。
- **数据备份 / 恢复**。
- **商品 / 往来单位 CSV 导入导出**。
- **期末处理（封账 / 结转）**。

## 🔍 发票智能识别

录入进项 / 出项发票时，可直接选择**图片（jpg / png / bmp / gif / webp）或 PDF**：

1. 系统先用 **OpenCV 解析增值税发票二维码**（结构化、最准确），提取发票代码、号码、日期、不含税金额、税额、价税合计等；
2. 若无二维码或解析不全，自动启用 **Tesseract 中文 OCR** 对票面文字做兜底识别（金额、日期、号码容错提取）；
3. 识别结果自动回填到表单，省去手工录入。

> 识别引擎（OpenCV + Tesseract）已随桌面安装包离线分发，无需联网，也无需额外配置。

## 🚀 部署方式

### 方式一：Windows 桌面（推荐个人 / 小团队）
下载安装包（如 `进销存管理系统安装包_v2.8.2.exe`），一路下一步选择安装目录即可。数据库默认落在程序目录，开箱即用、离线运行、启动后自动打开浏览器。

### 方式二：NAS / Docker 自部署（推荐团队 / 多端共享）
仓库已提供 `Dockerfile`、`docker-compose.yml`。容器内 `/data` 挂载到宿主目录持久化数据库，访问 `http://<服务器IP>:8899`。
详细步骤见 [`README-NAS.md`](README-NAS.md) 与 `wms_app/NAS部署指南.md`。

### 方式三：手机 App（上架计划）
`wms_app/mobile/` 提供 Capacitor 套壳配置，可复用现有前端打包为 iOS / Android App，连接云端后端实现外网访问。详见 `wms_app/docs/APP_STORE_PLAN.md`。

### 手机网页
前端已做响应式适配，手机浏览器访问同一局域网内的服务地址即可使用（窄屏自动变侧边抽屉）。

## 🗂 源码目录结构

```
.
├── README.md                  # 本说明
├── README-NAS.md              # NAS / Docker 部署说明
├── docker-compose.yml         # 容器编排
└── wms_app/
    ├── main.py                # 入口，路由挂载
    ├── database.py            # SQLite 初始化与升级
    ├── ocr_utils.py           # 发票图片/PDF 识别（二维码 + OCR）
    ├── period_guard.py        # 期末封账守卫
    ├── routers_*.py           # 各业务路由（base/order/inv/finance/system/auth/period）
    ├── static/
    │   ├── index.html         # 单文件前端
    │   └── manifest.webmanifest  # PWA 配置
    ├── mobile/                # Capacitor 移动端配置
    ├── installer.iss          # Inno Setup 安装脚本
    ├── Dockerfile             # 镜像构建
    └── requirements.txt       # Python 依赖
```

> 说明：数据库（`*.db`）、上传的发票图片（`uploads/`）、Tesseract 引擎（`tesseract/`）、打包产物（`dist/`、`installer/`）等运行时文件**不纳入版本库**，仅源码与部署配置入库，确保仓库干净、无隐私泄露。
